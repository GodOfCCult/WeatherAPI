# WeatherAPI - Консольное приложение для получения погоды

## Описание программы

Приложение представляет собой консольный скрипт на языке Python 3, который взаимодействует с внешним погодным сервером OpenWeatherMap по протоколу HTTP с использованием архитектурного стиля **REST API**.

Программа принимает на вход название города, отправляет запрос к серверу и выводит структурированные данные о текущих погодных условиях:
- Температура (с учётом ощущаемой)
- Влажность воздуха
- Атмосферное давление
- Скорость и направление ветра
- Описание погоды (облачно, ясно, дождь и т.д.)
- Время восхода и заката
